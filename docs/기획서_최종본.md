## 아이디어명

내 목소리 맞나요? — AI 음성 진위 확인 서비스

---

## 아이디어 요약

AI 음성 딥페이크를 탐지할 뿐 아니라, 왜 가짜인지를 시민 눈높이에서 설명하고 시각적으로 보여주는 음성 검증 서비스. 탐지 기술과 시민 사이의 간극을 AI가 메운다.

---

## 기획 배경

'엄마, 나 급하게 돈이 필요해' — 이 전화가 진짜 내 아이인지, AI가 만든 목소리인지 확인할 수 있다면? 경찰청 통계 기준 2025년 보이스피싱 피해액은 사상 최초 1조 원을 돌파(1조 566억 원)했으며, 건당 평균 피해액은 5,290만 원으로 전년 대비 2배 이상 증가했다. AI가 생성한 딥페이크 음성은 사람의 귀로 구별이 불가능하여, 기존 사후 대응만으로는 한계가 명확하다.

기존 딥페이크 탐지 서비스는 두 가지 한계가 있다. 첫째, MFCC 등 단일 특징에 의존하여 정교한 합성 음성을 놓친다. 둘째, '가짜입니다'라는 결과만 제공하여 시민이 왜 가짜인지 이해할 수 없다. 본 프로젝트는 이 두 가지를 동시에 해결한다. 다중 관점의 신호 분석으로 탐지 정확도를 높이고, LLM이 그 결과를 시민이 이해할 수 있는 말과 이미지로 전달한다.

학습 데이터는 국제 공인 데이터셋(ASVspoof)만을 사용하며, 사용자의 개인 음성을 수집·저장하지 않는다. 판별 결과만 제공하고 분석 중간 데이터는 즉시 폐기하여 오남용을 원천 차단한다. 탐지 결과는 확률 기반 신뢰도 점수로 제공하며, 최종 판단은 시민 본인이 내리도록 설계한다.

## 아이디어 주요 내용

▶ 서비스 흐름
가족·보호자가 의심 통화의 음성 메모를 업로드 → 이중 특징 추출 → CNN 진위 판별 → LLM이 판별 근거를 자연어로 설명 → 스펙트로그램 시각 비교와 함께 결과 제공

▶ 핵심 파이프라인 구조
음성 입력 → [멜 스펙트로그램 인코더 | 웨이블릿 인코더] → 특징 융합 → CNN 판별 → LLM 설명 → 결과 제공

▶ 핵심 차별화 요소

1. 시민 눈높이 설명 — "왜 가짜인가"를 말과 이미지로
기존 딥페이크 탐지 서비스는 '가짜입니다'라는 결과만 제공한다. 본 서비스는 탐지 결과를 "이 음성은 AI 생성 가능성이 높습니다. 고주파 영역에서 자연 음성에 없는 규칙적 패턴이 감지되었습니다"와 같이 자연어로 변환하고, 입력 음성과 정상 음성의 스펙트로그램을 나란히 보여준다. 시민이 '왜 가짜인지'를 직접 이해하고 판단할 수 있는 것이 핵심이다.

2. 이중 파이프라인 특징 추출 — 논문 기반 설계, 기존 방식 대비 31% 개선 실증
대부분의 딥페이크 탐지는 MFCC 등 단일 특징에 의존한다. 본 프로젝트는 스펙트럼 신호의 이중 인코더 구조를 제안한 RSPSSL(Hu et al., Light: Science & Applications, 2024) 논문의 설계를 참고하여, 멜 스펙트로그램(주파수 영역)과 웨이블릿 분석(시간-주파수 영역)을 병렬 적용하는 이중 파이프라인을 음성 도메인에 독자 구현하였다. 동일 조건 실험에서 단일 특징 대비 약 31% 개선(Dev EER 5.50% → 3.80%)을 확인하였다.

3. 누구나 쓸 수 있는 접근성 설계
1차 사용자는 가족·보호자이다. 자녀가 부모님의 의심 통화를 확인하는 시나리오를 기본으로 설계하며, 카카오톡 음성 메모를 업로드하면 즉시 결과를 확인할 수 있다.

## 프로젝트 계획

▶ 기술 스택: Python, PyTorch, librosa, PyWavelets / CNN(ResNet-18) / Claude API / Gradio
▶ 데이터셋: ASVspoof 2019 LA (ODC-By, 약 25,000 utterances)

▶ 사전 준비: 동일 조건(5,000 utterances)에서 멜 단일 Dev EER 5.50%, 이중 파이프라인 Dev EER 3.80%로 약 31% 개선을 확인하였다. 전체 데이터 학습 시 멜 단일 Dev EER 2.06%를 달성하였으며, 이중 파이프라인의 전체 데이터 학습 및 한국어 TTS 교차 검증을 진행 중이다. 핵심 모델은 본선 전 사전 학습 완료 상태로 진입하며, 본선에서는 파이프라인 통합과 UI 완성에 집중한다.

▶ 팀 구성(4인): 모델 개발 / 전처리·데이터 / LLM 연동·UI / 발표·기획

▶ 본선 MVP: ① 음성 업로드 → 진위 판별 + 신뢰도 점수  ② LLM이 판별 근거 자연어 설명  ③ 스펙트로그램 시각 비교

---

## 기대효과

▶ 시민 보호: 카카오톡 음성 메모를 업로드하면 즉시 진위 확인 가능. 중기적으로는 카카오톡 채널 또는 문자 기반 자동 분석 연동을 통해, 고령층이 별도 앱 설치 없이 분석 결과를 문자로 수신하는 구조로 확장한다.

▶ AI 리터러시: "딥페이크는 전문가만 판별할 수 있다"는 인식을 깨고, AI가 AI를 감시하는 구조를 시민이 직접 체험함으로써 디지털 리터러시를 높인다.

▶ 다중 도메인 확장: 본 파이프라인은 공공·민간 채널과 연계 가능한 API 구조로 설계한다. 실시간 통화 중 위험 알림, 금융기관 본인 인증 보조, 콜센터 수신 음성 자동 선별 등 다양한 시나리오에 동일한 탐지 엔진을 적용할 수 있으며, 영상 딥페이크 탐지 등 타 도메인으로의 확장도 가능하다.
